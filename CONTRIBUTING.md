# Mitmachen

Danke für dein Interesse an BarDrop.

* **Fehler melden:** Bitte über [Issues](https://github.com/zzuuuiii/BarDrop/issues/new/choose) mit der Vorlage „Fehler melden“. Hilfreich sind macOS-Version, BarDrop-Version (Einstellungen → Über BarDrop) und die Schritte, mit denen der Fehler auftritt.
* **Ideen:** Ebenfalls über Issues, Vorlage „Idee vorschlagen“.
* **Code beitragen:** Fork anlegen, Änderung in einem eigenen Branch, Pull Request auf `main`. Vor dem Zusammenführen baut GitHub Actions die App und führt alle Tests aus (`swift test`). Bitte neue Funktionen mit Tests absichern, wo es geht.

Beiträge stehen wie BarDrop selbst unter der [GPL-3.0](LICENSE).
